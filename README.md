# FinShield Frontend

FinShield Frontend is the user interface for the FinShield fraud detection project. It helps users analyze suspicious messages and view prediction details such as classification, confidence, risk level, and explanation.

## Backend Repository

- Backend repo: https://github.com/Adi-Dcpp/FinShield

## Demo Video

- Project demo video is included in this repository: [Watch Demo](./demo.mp4)

## Features

- Message fraud/safety analysis UI
- Confidence gauge and risk display
- Signal tags and AI explanation panel
- Dashboard and simulator flow
- Transaction history and review screens

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Icons

## Getting Started

### 1. Clone the repository

```bash
git clone <your-frontend-repo-url>
cd FinShield-Frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```
